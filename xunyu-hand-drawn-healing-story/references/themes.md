# 通用示例主题池（10 个 · 视频号 + 抖音双适配）

视觉规格：**白色极简手绘（通用）**——主题不限。  
内置 `theme_id: 01`…`10` 只是开箱可用的**示例选题**；用户可整段自拟任意题材覆盖（职场、旅行、萌宠、知识口播画面化等均可）。

叙事弧统一：**身份钩 → 压抑/等待 → 小反转/小确幸 → 可画面化余味**（禁止说教/金句升华结尾）。

流水线位置：选题为第一步 → [`pipeline.md`](pipeline.md) §1。未指定主题时默认 **`02`**（与 `defaults.yaml` 的 `default_theme_id` 一致）。

---

## 01 · 沉默的爱

| 项 | 内容 |
|---|---|
| 钩子公式 | 「TA 从不会说 X，只会用 Y 证明」 |
| 叙事弧提示 | 嘴笨/少言 → 日常沉默压抑 → 物件兑现爱意 → 余味落在物件温度 |
| 物件锚点 | 剥好的水果、热好的饭、叠好的衣服、留灯、旧拖鞋 |
| 视频号标题例 | 他不会说想我，只会把橘子剥好放在桌上 |
| 抖音标题例 | 嘴笨的人怎么表达爱？答案在桌上 |

## 使用方式

1. 用户话里已点名主题 → 映射到 `theme_id`；未提 → 默认 **`02` 时间与等待**（不要为选题单独追问）。 
2. 用该主题钩子写旁白；物件锚点进分镜与生图。 
3. 同时产出**视频号标题** + **抖音标题**。 
4. 用户自拟时：保留四段弧与白底极简画风，其余可改。
