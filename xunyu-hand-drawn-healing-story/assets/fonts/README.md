# Fonts

## Bundled (OFL)

- `ZCOOLKuaiLe-Regular.ttf` — ZCOOL KuaiLe / 站酷快乐体 
- `RoundedHandwrite.ttf` → symlink to the file above 
- `OFL-ZCOOLKuaiLe.txt` — license

Source: [Google Fonts ofl/zcoolkuaile](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile)

## Replace with your own

Place any licensed `.ttf` / `.otf` here and set in `config.yaml`:

```yaml
typography:
 font_file: assets/fonts/YourFont.ttf
```

Do **not** commit API keys or unlicensed commercial fonts for public release.
